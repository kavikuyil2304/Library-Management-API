# Prompt Library
## Library Management REST API — Capstone Project

### 1. API Development Prompt

**Prompt:**

Help me create a Library Management REST API using Python and FastAPI. Implement CRUD operations for books using GET, POST, PUT and DELETE methods.

**Purpose:** To develop the basic API structure and endpoints.

### 2. Pydantic Validation Prompt

**Prompt:**

Explain how to use Pydantic BaseModel and Field to validate book ID, title and author in FastAPI.

**Purpose:** To validate incoming book data.

### 3. HTTP Status Code Prompt

**Prompt:**

Explain the appropriate HTTP status codes for successful requests, duplicate book IDs, missing books and invalid request data.

**Purpose:** To implement proper error handling.

### 4. API Testing Prompt

**Prompt:**

Help me test all CRUD endpoints of my Library Management API using Pytest and FastAPI TestClient.

**Purpose:** To verify API functionality.

### 5. OpenAPI Verification Prompt

**Prompt:**

Help me verify whether all implemented FastAPI routes match the generated OpenAPI JSON documentation.

**Purpose:** To check API documentation accuracy.

### 6. Code Review Prompt

**Prompt:**

Review my FastAPI Library Management API code. Identify validation problems, incorrect status codes, missing error handling and possible improvements.

**Purpose:** To review code quality and identify issues.

### 7. Documentation Prompt

**Prompt:**

Help me prepare a research report, API design checklist, quiz, presentation and verification report for my Library Management API capstone project.

**Purpose:** To prepare project documentation.

### 8. AI Usage Declaration

ChatGPT was used as an AI assistance tool during this project for learning REST API concepts, understanding FastAPI, debugging code, preparing tests, reviewing API design and creating project documentation.

All generated suggestions and code were reviewed and tested by the student before being included in the project.

### 9. Important Note

The prompts listed above are representative examples of the AI assistance used during the project. They are documented for transparency and learning purposes.
