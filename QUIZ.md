# Library Management API — Quiz

## Questions

**1. What is FastAPI?**

**2. What is a REST API?**

**3. What is the purpose of GET in our project?**

**4. Which HTTP method is used to create a new book?**

**5. Which HTTP method is used to update a book?**

**6. Which HTTP method is used to delete a book?**

**7. What does HTTP status code 200 mean?**

**8. Why does our API return 201 when a book is created?**

**9. What does HTTP status code 404 mean?**

**10. Why do we return 400 when a duplicate book ID is submitted?**


## Answer Key

1. FastAPI is a Python framework for building APIs.
2. A REST API allows clients to interact with resources using HTTP methods.
3. GET retrieves book information.
4. POST.
5. PUT.
6. DELETE.
7. The request was successful.
8. 201 indicates that a resource was created.
9. The requested resource was not found.
10. To reject a duplicate book ID.
